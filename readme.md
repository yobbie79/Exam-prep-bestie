# EXAM PREP BESTIE ☁️

**Learn cloud concepts. Understand Azure. Pass with confidence.**

EXAM PREP BESTIE is a beginner-friendly study website designed to help learners prepare for the Microsoft Azure Fundamentals (AZ-900) certification exam. It combines structured study notes, original practice questions, clear explanations, and revision tools in one learning experience.

Developed for the **Vibe Coding Hackathon: AZ-900 Exam Prep Edition**, supporting the #1MillionDevs movement.

## 🎯 The Problem

Learning Azure for the first time can be challenging. Beginners often struggle with unfamiliar terminology, remembering definitions, and distinguishing between similar cloud services.

EXAM PREP BESTIE makes learning more approachable by organizing cloud concepts into manageable topics and helping learners test their understanding through practice.
